# Conformance vectors

Cross-implementation test vectors for the protocol-v1 crypto suite and wire
format. These are `geg`'s **own** canonical vectors; any conformant
implementation (this Python crypto layer, the TS frontend SDK, a future port)
must reproduce/verify every one. Passing them is the protocol conformance gate.

**Schema** (shared, language-neutral): compressed BLS12-381 points as hex,
scalars as decimal-digit strings, byte blobs as hex. Each file is
`{name, description, version, inputs, expected}`.

## Categories

Adopted from the reference SDK's cross-language suite (verified by geg's crypto
in `tests/test_conformance_vectors.py`):

- `encrypt/` — ElGamal ciphertext byte-parity under pinned randomness
- `dleq/` — Chaum-Pedersen DLEQ verify
- `or/` — (B+1)-branch OR proof verify
- `budget/` — exact + atMost budget proof verify
- `schnorr/` — Schnorr signature verify
- `decrypt-share/` — decryption-share DLEQ verify
- `ballot/` — full ballot validity-proof + signature (variant A / exact = level 1;
  variant B / atMost ballots are level 2, skipped with a reason)
- `tally/` — Lagrange combine + BSGS recovery

geg-native (protocol extensions the reference SDK doesn't cover), generated by
`scripts/gen_vectors.py`:

- `attestation/` — weighted `ATTESTATION_V1` + legacy scheme; positive **and**
  negative cases (tampered weight, wrong-election binding, over-maxWeight)
- `flow/` — a complete variant-A/exact/weighted election (config, 5 ballots incl.
  one invalid + one duplicate, aggregate with exclusions, t+1 shares, result),
  replayable to reproduce the admitted set, aggregate, and tally

Build-style fixtures (`*_known.json`) pin all randomness and are checked for
exact byte reproduction by `tests/test_parity_vectors.py`.

## Running the gate

```sh
pytest tests/test_conformance_vectors.py tests/test_parity_vectors.py
```

The reference TS SDK already verifies the shared categories (they are its own
vectors); geg now verifies the same files, establishing cross-language parity.
When the TS frontend SDK is built into this repo it consumes these same JSON
files — including the geg-native `attestation/` and `flow/` vectors.

Regenerate the geg-native vectors with `python scripts/gen_vectors.py`.
